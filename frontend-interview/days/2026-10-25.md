## 一、HTML 与语义化（2 题）

### 1.1 [简单] 常见的 HTML 语义化标签有哪些？为什么推荐用语义化标签而不是全部写成 div？

**参考要点**：header/nav/main/aside/section/article/footer/figure/label 等。收益：SEO 抓取更准、屏幕阅读器可按地标快速跳转、DOM 结构可读性好、后续改版与样式定位成本低；div 无语义，所有节点在可访问性树上被同等对待。

### 1.2 [中等] 前端需要做哪些 SEO 优化？为什么纯 SPA 对 SEO 不友好？

**参考要点**：title/description 唯一且含关键词、语义化标签、h1-h6 层级合理、图片 alt、canonical、robots.txt 与 sitemap、结构化数据 JSON-LD、路由可抓取。SPA 首屏 HTML 为空壳，爬虫拿不到正文，需 SSR/SSG/预渲染补齐内容，并配合动态路由的 SSR 规则。

## 二、CSS 与布局工程（2 题）

### 2.1 [困难] 什么是层叠上下文与层叠顺序？为什么 transform、opacity 会"意外"改变元素的层级关系？

**参考要点**：层叠上下文由 position+z-index 非 auto、opacity<1、transform、filter、will-change、isolation:isolate、flex/grid 子项 z-index 非 auto 等创建；同层内按 z-index 再按文档序排序。transform/opacity 会创建层叠上下文并成为包含块，使子元素的 z-index 只在本层内生效，因此表现为"层级被改变"。

### 2.2 [中等] 什么是 BFC（块级格式化上下文）？哪些属性会触发 BFC，它能解决什么问题？

**参考要点**：触发条件：float、position:absolute/fixed、display:flex/grid、overflow 非 visible、contain:content、will-change 等。作用：阻止外边距合并、包含浮动子元素、不与浮动元素重叠、让 margin:auto 在垂直方向居中生效。

## 三、JavaScript 核心（2 题）

### 3.1 [中等] var、let、const 的区别是什么？闭包有什么作用和典型使用场景？

**参考要点**：var 是函数作用域、声明提升、可重复声明；let/const 是块作用域、存在暂时性死区、同一作用域不可重复声明，const 绑定不可变但对象内部仍可变。闭包 = 函数 + 它定义时的词法环境，常用于私有变量、柯里化、防抖节流、事件监听器缓存、循环中绑定变量。

### 3.2 [中等] 浅拷贝与深拷贝的区别？实现一个深拷贝要注意什么？

**参考要点**：展开运算符/Object.assign/Array.slice 只复制一层引用。深拷贝要递归复制。JSON.parse(JSON.stringify) 会丢失 undefined/function/Symbol、Date 变字符串、无法处理循环引用。手工实现需处理循环引用（WeakMap 缓存）、Map/Set、Date/RegExp、Symbol 键，并用 Object.prototype.toString 做类型判断。

## 四、异步编程与事件循环（2 题）

### 4.1 [中等] 手写 Promise.all / Promise.allSettled 要注意哪些细节？

**参考要点**：all：任一 reject 立即 reject（但其他请求仍继续），空数组立即 resolve，结果按输入顺序而非完成顺序；allSettled 永不 reject，返回 {status, value|reason} 数组；race 取第一个 settle 的；any 取第一个 fulfilled，全部失败才 reject。非 Promise 值要 Promise.resolve 包装。

### 4.2 [中等] 宏任务（macroTask）和微任务（microTask）分别有哪些？它们的执行顺序是怎样的？

**参考要点**：宏任务：script、setTimeout/setInterval、I/O、UI 事件、MessageChannel、postMessage；微任务：Promise.then/catch/finally、queueMicrotask、MutationObserver（Node 还有 process.nextTick）。每轮取一个宏任务执行完后立刻清空整个微任务队列，再进入下一轮。

## 五、TypeScript（2 题）

### 5.1 [简单] any、unknown、never、void 四个类型有什么区别？工程上该用哪个？

**参考要点**：any 关闭类型检查且会向外传播错误，慎用；unknown 是 any 的安全版，使用前必须收窄；never 表示不可能出现的值，可用于穷尽检查和永不返回的函数；void 表示忽略返回值。第三方/动态数据一律用 unknown 再收窄。

### 5.2 [中等] interface 与 type 有什么区别？declare、namespace、*.d.ts 分别用来做什么？

**参考要点**：interface 只能描述对象类型、可 extends、可声明合并；type 是别名，支持联合/条件/映射/元组。declare 用于声明 ambient 全局变量与模块；namespace 用来在模块内组织类型或旧式全局命名空间；*.d.ts 描述第三方库的模块类型，@types 提供内置库类型。

## 六、React（2 题）

### 6.1 [中等] React 性能优化有哪些手段？React.memo、useMemo、useCallback 分别解决什么问题？

**参考要点**：React.memo 在 props 浅比较相等时跳过子组件重渲染；useMemo 缓存昂贵计算结果或引用；useCallback 稳定函数引用便于传给 memo 子组件或作为 effect 依赖。配合 React DevTools Profiler 定位瓶颈；此外还有状态下沉、列表 key 稳定、虚拟列表、避免内联对象/箭头函数。memo 本身有比较成本，不要滥用。

### 6.2 [简单] 什么是 Virtual DOM？它解决了什么问题？React 的更新流程是怎样的？

**参考要点**：用 JS 对象描述 UI，把状态变化批量计算成最小 DOM 操作，避免直接命令式操作 DOM。流程：setState → 调度器排队 → render 生成新元素树 → diff/reconciliation 比对 → commit 更新真实 DOM；同层子节点靠 key 保持身份标识。

## 七、Vue（2 题）

### 7.1 [中等] Vue 2 的响应式原理是什么？Vue 3 做了哪些改变？

**参考要点**：Vue 2 用 Object.defineProperty 逐个劫持 data 属性，依赖收集在 getter、派发在 setter；数组需重写 push 等方法才能侦测，新增属性需 Vue.set。Vue 3 改用 Proxy 代理整个对象，新增/删除属性都能侦测，Proxy 代理的是原对象而 Vue 2 生成的是带访问器的副本；Vue 3 依赖收集用 track/trigger。

### 7.2 [中等] computed 和 watch 有什么区别？watch 的 deep、immediate、flush 分别怎么用？

**参考要点**：computed 是缓存的派生值，依赖不变不重算，适合模板取值；watch 是副作用，支持异步、可配置深度监听。deep 深度比较（代价大，尽量改用不可变数据），immediate 首次立即执行，flush 可选 pre/post/sync 决定回调时机。watchEffect 会自动收集依赖。

## 八、工程化与构建（2 题）

### 8.1 [中等] 如何设计前端项目的工程化规范？ESLint、Prettier、Husky、lint-staged、commitlint 分别做什么？

**参考要点**：ESLint 做静态检查（规则 + 插件），Prettier 负责格式化（与 ESLint 分工避免冲突），Husky 挂 Git hooks，lint-staged 只对本次暂存文件执行检查，commitlint 约束 commit message 规范，CI 再做一次全量校验。提交前跑 pre-commit，重要分支跑 pre-push。

### 8.2 [中等] Webpack 的核心概念有哪些？常用的构建优化手段有哪些？

**参考要点**：核心概念：entry/output、loader、plugin、module、chunk、mode、devServer。优化：splitChunks 分包、动态 import 代码分割、tree-shaking 配合 sideEffects、构建缓存（babel cache、持久化 cache）、Terser/cssnano 压缩、小资源内联、DllPlugin、并行构建与多线程压缩。

## 九、Node.js / BFF / Serverless（2 题）

### 9.1 [中等] Node.js 的事件循环和浏览器有什么区别？EventEmitter 是什么？

**参考要点**：Node 有多个阶段：timers、pending callbacks、idle/prepare、poll、check（setImmediate）、close callbacks；process.nextTick 队列优先于 Promise 微任务。EventEmitter 是事件驱动基类，支持 on/once/emit/off，error 事件若无人监听会直接抛异常。

### 9.2 [中等] Serverless / 云函数（如本仓库 cloudfunctions 目录）有哪些特点？冷启动、连接复用、超时限制如何应对？

**参考要点**：特点：按量计费、免运维、自动弹性、事件驱动。冷启动来自运行时初始化，用预置并发/最小实例/provisioned concurrency 缓解；连接复用要复用数据库与 Redis 连接、避免频繁建连；注意执行超时与内存上限，函数要幂等并支持重试；不适合长连接与长耗时任务。

## 10、网络与 HTTP（2 题）

### 10.1 [简单] 常见 HTTP 状态码有哪些？401 与 403、301/302/307/308 分别有什么区别？

**参考要点**：2xx 成功（200/201/204）、3xx 重定向（301 永久、302 临时、304 协商缓存、307/308 保持方法与 body）、4xx 客户端（400 参数错、401 未认证、403 已认证但禁止、404、409 冲突、429 限流）、5xx 服务端（500/502/504）。302 历史上可能把 POST 改为 GET，307/308 不会。

### 10.2 [中等] HTTP 缓存机制是怎样的？强缓存和协商缓存的区别是什么？

**参考要点**：强缓存：Cache-Control（max-age、no-cache、no-store、private/public、s-maxage）与 Expires，命中则不发请求；no-cache 表示必须协商而非不缓存。协商缓存：If-None-Match/ETag、If-Modified-Since/Last-Modified，命中返回 304。ETag 优先级高于 Last-Modified，弱校验 Last-Modified 精度只到秒。

## 11、浏览器原理与渲染（2 题）

### 11.1 [中等] 从输入 URL 到页面渲染完成，浏览器经历了什么？

**参考要点**：DNS 解析 → TCP 连接 → TLS 握手 → 发送 HTTP 请求 → 收到响应 → 解析 HTML 构建 DOM → 解析 CSS 构建 CSSOM → 合成渲染树 → 布局（Layout）→ 绘制（Paint）→ 合成（Composite）。JS 脚本可能阻塞解析；关键渲染路径是首屏优化重点。

### 11.2 [中等] Service Worker 是什么？PWA 的核心能力有哪些？限制是什么？

**参考要点**：Service Worker 是独立线程的请求代理，可拦截 fetch 实现离线与自定义缓存策略（precache/runtime）。PWA 能力：可安装、可离线、推送通知、后台同步。限制：必须 HTTPS、仅部分浏览器支持、更新需配合 skipWaiting/clientsClaim、缓存需版本化清理。

## 12、前端性能优化（2 题）

### 12.1 [简单] 图片、字体、静态资源分别有哪些优化手段？

**参考要点**：图片：webp/avif、srcset/sizes 尺寸适配、loading=lazy 或 IntersectionObserver 懒加载、CDN 压缩、避免用 Base64 内联大图；字体：woff2 + 子集化 + font-display + preload 关键字体；静态资源：hash 文件名配长缓存、gzip/br、抽离公共包、必要时上 CDN。

### 12.2 [中等] 前端有哪些核心性能指标？如何采集 Core Web Vitals？

**参考要点**：CWV 包含 LCP（最大内容绘制）、INP（交互到下一次绘制，取代 FID）、CLS（累积布局偏移）；辅助指标 FCP、TTFB、INP 长任务。用 PerformanceObserver/Performance API 或 web-vitals 库采集；实验室数据用 Lighthouse/RUM 分开看，真实用户监控更能反映线上体验。

## 13、前端安全（2 题）

### 13.1 [中等] XSS 有哪些类型？如何防御？

**参考要点**：类型：存储型、反射型、DOM 型。防御：按输出上下文编码（HTML/属性/JS/URL）、避免 innerHTML/eval/Function、必须渲染富文本时用 DOMPurify 白名单过滤、配置 CSP、Cookie 设 httpOnly + Secure、HTTPS 传输。框架默认转义（React 危险 API 除外），但 dangerouslySetInnerHTML 等会绕过。

### 13.2 [中等] 前端如何安全地存储与传递敏感信息？JWT 的优缺点是什么？

**参考要点**：密码绝不落前端；access token 存内存变量，refresh token 用 httpOnly + Secure + SameSite Cookie；敏感操作由服务端二次校验。JWT 优点是无状态、可校验、可跨服务；缺点是无法主动失效、体积大、密钥泄露即失守、需要 token 刷新与黑名单机制配合。

## 14、数据结构与算法（2 题）

### 14.1 [中等] 树和图的遍历如何实现？BFS 与 DFS 的应用差异是什么？

**参考要点**：DFS 用递归或显式栈（深树避免爆栈），BFS 用队列 + visited 集合。二叉树常见前/中/后序与层序遍历；图中用于连通性、环检测、拓扑排序、最短路径（BFS 求无权最短路，Dijkstra 求带权最短路）。

### 14.2 [简单] 数组去重、数组扁平化、对象数组按字段排序这类题分别怎么做？

**参考要点**：去重：Set、filter+indexOf、Map 按字段去重；扁平：flat(Infinity)、reduce+concat、flatMap；排序：sort 比较器必须返回负/正/0，注意不要用减法处理超大数字或字符串。注意复杂度与边界（空数组、NaN、稳定排序）。

## 15、状态管理与数据流（2 题）

### 15.1 [中等] 前端状态如何分类？为什么不能把所有状态塞进一个全局 store？

**参考要点**：分类：局部 UI 状态、全局客户端状态（登录信息、主题）、服务端状态（缓存 + 请求 + 同步）、URL 状态、表单状态。混在一起会导致无关状态变更触发大范围重渲染、调试困难。服务端状态优先用 SWR/React Query 这类带缓存与失效的方案，而不是手写进全局 store。

### 15.2 [中等] MobX、Zustand、Pinia、Vuex 各自特点与选型依据？

**参考要点**：MobX 基于可观察对象的自动依赖推导（observable/action/computed），心智负担小；Zustand 轻量、基于 selector 订阅、适合 React 小中型项目；Pinia 是 Vue 3 官方方案，组合式 API 写法、无 mutations、可 SSR；Vuex 是 Vue 2 方案（state/mutations/actions/modules）。选型看团队规模、状态复杂度和框架。

## 16、可视化与图形（2 题）

### 16.1 [中等] 如何实现图表联动与 tooltip 定制？

**参考要点**：联动：echarts.connect/group 同步 axisPointer，或用 dispatchAction 广播事件；tooltip 用 formatter 返回 HTML/富文本（支持 rich text）、axisPointer link；跨图表联动可用事件总线或状态统一管理 tooltip 状态。

### 16.2 [中等] ECharts 有哪些核心能力？如何按需引入优化体积？

**参考要点**：能力：折线/柱状/饼/散点/地图/关系图/仪表盘、dataset、dataZoom、tooltip、markLine、响应式与大数据量降采样；渲染器可选 Canvas 或 SVG。按需引入：只注册需要的 charts + components + renderer（echarts/core），避免全量 echarts 打进主包。

## 17、移动端与跨端（2 题）

### 17.1 [中等] 移动端适配有哪些方案？rem、vw/vh、媒体查询、CSS 像素与设备像素比的关系？

**参考要点**：DPR = 物理像素 / CSS 像素。方案：rem（动态设置根字号 + postcss-pxtorem）、vw/vh（1vw = 1% 视口宽）、flex/grid 流式布局、@media 断点栅格、viewport meta；现代方案用 clamp() 做流式字号、容器查询适配组件级响应。

### 17.2 [中等] 小程序与 H5 有什么区别？小程序与 H5 如何通信？

**参考要点**：小程序是双线程（逻辑层/渲染层隔离）、无 DOM、依赖平台 API、有包体积与审核限制；H5 是标准 Web。通信：web-view 组件内通过 postMessage + JSSDK 桥接；小程序与 H5 互跳通过 URL 参数传递数据（注意长度限制与编码）。

## 18、组件库与设计系统（2 题）

### 18.1 [中等] 组件库如何做到按需引入、减少打包体积？

**参考要点**：产物同时提供 ESM 与 CJS 并标注 sideEffects，配合 babel-plugin-import 或 treeshaking 做到按需引入样式；图标独立成包按需打包；避免在组件顶层执行副作用；构建产物体积纳入 CI 基线监控。

### 18.2 [中等] 一个可用的组件库需要提供哪些能力？设计一个 Button 组件要注意什么？

**参考要点**：能力：一致的视觉规范、完整的 API 设计、受控/非受控双模式、可访问性、主题定制与暗色模式、国际化、TypeScript 类型、按需加载与 tree-shaking、文档与用例。Button：语义标签（button/a）、loading/disabled/icon/尺寸/形状/块级、键盘可达、焦点样式、防重复点击。

## 19、质量保障与工程效率（2 题）

### 19.1 [中等] 前端有哪些测试类型？如何划分测试金字塔？

**参考要点**：类型：单元测试（Vitest/Jest）、组件/集成测试（Testing Library）、E2E（Playwright/Cypress）、视觉回归、契约测试、性能与兼容性测试。金字塔建议单元测试多、E2E 少（慢且脆）；以「风险 × 变更频率」决定投入，核心链路才上 E2E。

### 19.2 [中等] 前端项目的 CI 流水线一般包含哪些步骤？

**参考要点**：常见顺序：安装（npm ci + 缓存）、lint、类型检查（tsc --noEmit）、单元测试、构建、产物上传与体积校验、E2E/视觉回归、部署到 CDN 或容器、冒烟验证与回滚预案。质量门禁（覆盖率、lint 报错、产物体积超阈值）不通过即阻断合并。

## 20、部署运维与架构（2 题）

### 20.1 [中等] BFF 与 API 网关如何配合？前端直连后端有什么风险？

**参考要点**：网关统一做路由、鉴权、限流、灰度、日志；BFF 面向前端做视图聚合与字段裁剪，可按端拆分。直连风险：暴露后端拓扑与内部协议、传输冗余字段导致体积变大、多端多请求往返、CORS 复杂、版本不一致、无法针对端定制与缓存。

### 20.2 [中等] 前端如何部署上线？CDN、Nginx、Docker 在其中分别做什么？

**参考要点**：流程：构建产出带内容 hash 的静态文件 → 上传 CDN 或静态服务器 → Nginx 做静态托管、gzip/brotli、缓存头、反向代理、SPA 回退（try_files $uri /index.html）、HTTPS 证书。Docker：多阶段构建（node 阶段构建 → nginx 阶段运行）、镜像分层与最小化、配合编排做滚动更新。SSR 应用则需要 Node 进程常驻。
