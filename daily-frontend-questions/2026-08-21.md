## 一、HTML

1. **语义化标签**：请列举至少 5 个 HTML5 新增的语义化标签，并说明 `<section>`、`<article>`、`<aside>` 三者使用场景的区别。
2. **DOCTYPE 的作用**：`<!DOCTYPE html>` 的本质是什么？如果页面不写它，浏览器会以何种模式渲染，可能带来什么问题？
3. **script 标签的 defer / async / type="module"** 三者执行时机有何区别？在 ES Module 中默认行为又是怎样的？

## 二、CSS

1. **盒模型**：标准盒模型（`content-box`）与 IE 怪异盒模型（`border-box`）的区别是什么？`box-sizing` 设为 `border-box` 在实际工程中有什么好处？
2. **居中方案**：请至少写出 3 种让一个未知宽高的子元素在父容器中水平垂直居中的 CSS 方案，并比较它们的适用场景。
3. **BFC**：什么是 BFC（Block Formatting Context）？触发条件有哪些？请举例说明 BFC 在解决外边距塌陷和清除浮动中的作用。

## 三、JavaScript

1. **原型与继承**：请画出 `function Person() {}; const p = new Person();` 的原型链图，并说明 `p.__proto__`、`Person.prototype`、`Person.__proto__` 分别指向什么。
2. **this 指向**：以下代码分别输出什么？为什么？
   ```js
   const obj = {
     name: 'A',
     fn() {
       console.log(this.name);
     },
   };
   const f = obj.fn;
   f();
   obj.fn();
   new obj.fn();
   ```
3. **事件循环**：请描述浏览器中宏任务（macroTask）与微任务（microTask）的执行顺序。`Promise.then`、`setTimeout`、`requestAnimationFrame`、`queueMicrotask` 各自属于哪一类？
4. **闭包**：什么是闭包？它可能导致什么内存问题？请写出一个利用闭包实现"模块私有变量"的例子。

## 四、TypeScript

## 五、Vue

## 参考答案要点（简）

> 仅给出答题框架，详细作答请结合自身理解展开。

- **HTML3**：模块默认 `defer`，模块间按依赖顺序；`defer` 整个文档解析完后按序执行；`async` 加载完即执行。
- **CSS2**：Flex (`display:flex; justify-content:center; align-items:center;`)、Grid (`place-items:center`)、绝对定位 + `transform: translate(-50%, -50%)`、Table-cell。
- **JS3**：`Promise.then` / `queueMicrotask` 为微任务；`setTimeout` 为宏任务；`rAF` 属于渲染前调度，常归为宏任务（在每帧渲染前）。
- **TS3**：协变 = 子类型方向一致；逆变 = 反向。`strictFunctionTypes` 开启后函数参数以逆变方式检查（部分场景兼容 `strict` 仍允许更宽参数）。
- **Vue1**：Proxy 拦截动态新增/删除属性、数组索引修改、Map/Set 等，无需 `$set`。
- **React1**：Fiber 把同步渲染拆成可中断的工作单元，浏览器通过 `MessageChannel` 在 5ms 切片内调度 `performUnitOfWork`。
- **Node1**：`process.nextTick` 优先级最高（在当前阶段结束后立即执行），其次微任务，然后进入下一阶段，`setImmediate` 在 check 阶段。
- **网络1**：DNS 解析 → TCP 三次握手 → TLS 四次握手（HTTP/2 协商）→ HTTP 请求 → 解析 HTML 构 DOM、CSS 构 CSSOM → 合成渲染树 → 布局 → 分层 → 绘制 → 合成。
- **工程1**：Vite dev 基于浏览器原生 ESM + esbuild 预构建，绕过打包所以启动快；生产用 Rollup。
- **性能1**：衡量指标包括 FCP、LCP、TTI、CLS、INP（Core Web Vitals）。
- **安全1**：存储型 XSS 持久化在数据库；反射型藏在 URL；DOM 型完全在浏览器端通过 `innerHTML` / `eval` 等触发。
