## 一、HTML / 语义化（2 题）

1. **`<section>`、`<article>`、`<div>` 三者有何区别？什么场景下应该用 `<section>` 而非 `<article>`？**
   参考要点：内容独立性、是否具有可被独立分发的语义、是否有标题元素、是否影响文档大纲（outline）。

2. **`<script>` 标签的 `defer`、`async`、`type="module"` 三种加载/执行方式各有什么特点？它们与 DOMContentLoaded、load 事件的先后顺序是怎样的？**
   参考要点：阻塞解析 vs 不阻塞；执行时机（DOM 构建前/后）；module 默认 defer；多个脚本的执行顺序保证。

## 二、CSS 基础与进阶（4 题）

3. **盒模型（content-box vs border-box）的区别是什么？实际项目中为什么更推荐 `border-box`？如果要全局设置，怎么写？**
   参考要点：`box-sizing`、内边距/边框是否计入 width；`* { box-sizing: border-box }` 与 `::before, ::after`。

4. **请解释 BFC（块级格式化上下文）的形成条件、它能解决哪些实际问题（如外边距塌陷、浮动父容器高度坍塌等）。**
   参考要点：`overflow` 不为 visible、`display: flow-root`、浮动、`position: absolute/fixed`、行内块等。

5. **CSS 中实现水平垂直居中至少列出 5 种方式，并说明各自的兼容性和适用场景。**
   参考要点：`flex`、`grid`、`absolute + transform`、`absolute + 负 margin`、`line-height + vertical-align`、`table-cell` 等。

6. **说说 `position: sticky` 的工作原理、常见失效场景，以及与 `fixed` 的关键区别。**
   参考要点：粘性定位的包含块、最近滚动祖先、`top` 触发条件、父元素 `overflow: hidden` 会导致失效。

## 三、JavaScript 基础（4 题）

7. **JavaScript 中的基本类型和引用类型分别有哪些？为什么要区分？判别方式（`typeof` / `instanceof` / `Object.prototype.toString.call`）的差异？**
   参考要点：7 种基本类型；栈/堆内存；引用类型按引用比较；判别方法的边界与陷阱（`typeof null === 'object'` 等）。

8. **什么是变量提升（hoisting）？`var`、`let`、`const` 在声明、暂存死区、重复声明、可重新赋值上的差异？**
   参考要点：函数声明整体提升、变量声明只提升声明；TDZ；全局声明与 `window` 属性的关系。

9. **解释原型与原型链：`__proto__`、`prototype`、`constructor` 三者关系是什么？`new` 操作符在背后做了哪些事？**
   参考要点：构造函数显式原型 vs 实例隐式原型；链式查找；new 的 4 步（创建对象、链接原型、绑定 this、返回对象）。

10. **闭包是什么？经典应用场景有哪些？循环中如何用闭包正确捕获每次的索引（举例说明）？**
    参考要点：函数 + 自由变量；模块化、私有变量、柯里化；`var` 循环中用 IIFE 或 `let`。

## 四、JavaScript 进阶 / ES6+（4 题）

11. **Promise 的三种状态及其转换规则是怎样的？`.then` 返回新 Promise 的链式调用语义是什么？**
    参考要点：pending / fulfilled / rejected；不可逆；返回值穿透与异常冒泡。

12. **`async/await` 底层是怎么实现的？它和 `Promise`、`Generator` 的关系是什么？**
    参考要点：协程语义；`await` 暂停点；自动 `Promise.resolve` 包装；错误处理 try/catch 与 `.catch`。

13. **箭头函数和普通函数在 `this`、作为构造函数、`arguments` 对象、能否作为 `Generator` 上的差异？**
    参考要点：词法 this、不能 new、没有 arguments、不能做 generator。

14. **`Map` / `WeakMap`、`Set` / `WeakSet` 各自的特点和典型使用场景分别是什么？**
    参考要点：键的类型、可迭代、WeakMap 弱引用防止内存泄漏（DOM 节点元数据存储）。

## 五、TypeScript（3 题）

15. **TypeScript 中 `interface` 与 `type` 的区别是什么？什么场景更推荐哪个？**
    参考要点：合并声明（interface）、union/intersection（type）、函数重载、声明合并。

16. **TypeScript 的泛型（Generics）是什么？请手写一个函数签名：约束 `T` 必须包含 `length` 属性并返回该长度。**
    参考要点：`function getLen<T extends { length: number }>(x: T): number`。

17. **`any`、`unknown`、`never` 三个类型分别适用于什么场景？`unknown` 相比 `any` 的安全性体现在哪？**
    参考要点：unknown 不可直接操作，需先收窄；never 用于穷尽判断与不可能分支。

## 六、React（4 题）

18. **React 中受控组件与非受控组件的区别是什么？各自的适用场景？**
    参考要点：受控通过 state/受控回调；非受控通过 ref；表单库设计取舍。

19. **简述 React Hooks 的运行机制：为什么不能在条件语句中调用 Hook？Fiber 链表在其中扮演什么角色？**
    参考要点：Hooks 链表与渲染链表一一对应；按调用顺序匹配；Fiber 的 `memoizedState`。

20. **React 性能优化手段有哪些？请至少说出 6 种并说明原理。**
    参考要点：`React.memo`、`useMemo`、`useCallback`、`useTransition`/`useDeferredValue`、列表 `key`、虚拟列表、懒加载、Suspense、并发渲染。

21. **React 18 的并发渲染（Concurrent Rendering）带来了哪些新能力？`useTransition` 与 `useDeferredValue` 的差异？**
    参考要点：可中断渲染、优先级调度；transition 标记非紧急更新；deferredValue 滞后派生值。

## 七、Vue（4 题）

22. **Vue 3 的响应式核心是什么？`Proxy` 相比 Vue 2 的 `Object.defineProperty` 解决了哪些问题？**
    参考要点：依赖收集（track/trigger）、懒代理、数组下标/length、新增属性的处理、Reflect。

23. **Vue 3 中 `ref` 和 `reactive` 的区别？什么情况下应该用 `ref`？模板中自动解包的边界是什么？**
    参考要点：基本类型 ref、对象 ref 自动 `reactive`；reactive 失去响应式边界（解构、ref 替换）。

24. **Vue 的 `computed` 与 `watch` 各自的使用场景与差异？`watchEffect` 又是什么？**
    参考要点：computed 同步派生、缓存；watch 显式依赖、副作用；watchEffect 自动收集、立即执行。

25. **Vue 中 `v-if` 与 `v-show` 的区别是什么？它们在虚拟 DOM、生命周期和性能上有什么影响？**
    参考要点：v-if 真实条件渲染（创建/销毁组件）；v-show 仅切换 display。

## 八、Node.js / 后端基础（3 题）

26. **Node.js 的事件循环（Event Loop）和浏览器中的事件循环在宏任务/微任务执行顺序上有什么不同？**
    参考要点：Node 各阶段（timers、pending callbacks、idle、poll、check、close）；`process.nextTick` vs `Promise.then`。

27. **Node 中 `process`、`Buffer`、`Stream` 各自的作用？什么场景下应该使用流（Stream）？**
    参考要点：大文件读写、内存占用、管道 pipe。

28. **什么是中间件（Middleware）？请手写一个 Koa/Express 风格的中间件签名，并说明洋葱模型。**
    参考要点：`async (ctx, next) => { ... await next() ... }`；执行顺序与异常穿透。

## 九、前端工程化（4 题）

29. **Webpack 的构建流程大致分几步？Loader 和 Plugin 的区别是什么？**
    参考要点：初始化 → 编译 → 入口 → 模块解析 → loader 链 → 依赖图 → seal → emit；loader 是转换器、plugin 是生命周期钩子。

30. **Vite 为什么开发环境下启动很快？它和 Webpack 的核心差异是什么（按需编译、ESM、HMR）？**
    参考要点：基于浏览器原生 ESM；esbuild 预构建依赖；按需加载。

31. **什么是 tree-shaking？它的生效条件（ES Module、`sideEffects`、`mode: production`）是什么？**
    参考要点：静态分析、无副作用标记、生产模式。

32. **前端模块化方案（CommonJS、AMD、UMD、ESM）的差异和演进，以及 `<script type="module">` 与 CommonJS 的本质区别。**
    参考要点：同步/异步、运行时/编译期、值拷贝/引用绑定、循环依赖处理。

## 十、浏览器原理（3 题）

33. **从输入 URL 到页面渲染完成，浏览器大致经历了哪些阶段？哪些阶段耗时最长？**
    参考要点：DNS、TCP/TLS、HTTP 请求、解析（HTML→DOM、CSS→CSSOM）、Render Tree、Layout、Paint、Composite。

34. **浏览器渲染中的「重排（Reflow）」与「重绘（Repaint）」的区别？哪些操作会引起重排？如何最小化？**
    参考要点：几何属性触发 reflow；颜色/visibility 触发 repaint；批量写、读写分离、脱离文档流、will-change、contain。

35. **什么是 V8 的隐藏类（Hidden Class）和内联缓存（IC）？它们对对象属性访问的性能影响是什么？**
    参考要点：V8 对对象结构建模；相同 hidden class 命中 IC；动态添加属性顺序不同导致去优化。

## 十一、网络 / HTTP（3 题）

36. **HTTP/1.1、HTTP/2、HTTP/3 的核心改进分别是什么？HTTP/2 的多路复用为什么还要配合头部压缩（HPACK）？**
    参考要点：二进制分帧、首部压缩、服务器推送；HTTP/3 基于 QUIC/UDP 解决队头阻塞。

37. **常见 HTTP 状态码（如 200、301、302、304、400、401、403、404、500、502、503）分别表示什么？**
    参考要点：1xx 信息、2xx 成功、3xx 重定向（永久 vs 临时）、4xx 客户端、5xx 服务端；304 协商缓存。

38. **强缓存和协商缓存分别如何工作？`Cache-Control`、`Expires`、`ETag`、`Last-Modified` 的关系？**
    参考要点：本地命中 vs 304 回源；`max-age`、`no-cache` vs `no-store`；ETag 优先级、If-None-Match。
