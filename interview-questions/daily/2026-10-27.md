## 一、HTML（2 题）

**1. script 标签中 `defer` 和 `async` 有什么区别？** 🟡
**2. 什么是 HTML 语义化？为什么要语义化？** 🟡

**参考答案**
1. `defer`：异步下载，解析到该标签时不阻塞，等文档解析完成、DOMContentLoaded 前按顺序执行。`async`：异步下载，下完立刻执行，**不保证顺序**。两者都不阻塞 HTML 解析，都不支持 `document.write`。
2. 用 `header/nav/main/article/aside/footer/section` 表达结构而非全用 `div`。收益：SEO（按语义抓取）、无障碍（读屏、键盘可达）、可读性与维护性、浏览器与工具行为更可预期。

## 二、CSS（2 题）

**3. 什么是 CSS 盒子模型？`box-sizing` 的作用？** 🟢
**4. CSS 选择器有哪些？优先级如何计算？** 🟡

**参考答案**
3. 标准模型 `content-box`：`width` 只算内容区；`border-box`：`width` 含 padding 与 border。全局 `* { box-sizing: border-box }` 更贴近设计稿。
4. 类型/类/ID/通配、后代/子/相邻/兄弟、伪类/伪元素、属性选择器。优先级：`!important` > 内联 > `#id` > 类/属性/伪类 > 标签/伪元素 > 通配；**同权重看书写顺序**。`:not()/:is()` 取参数自身最高权重，`:where()` 恒为 0。

## 三、JavaScript 语言基础（2 题）

**5. 深拷贝和浅拷贝有什么区别？JS 怎么实现深拷贝？** 🟡
**6. 什么是防抖和节流？如何用 JS 实现？** 🟢

**参考答案**
5. 浅拷贝只复制一层，嵌套对象仍是同一引用（`Object.assign`、展开、`slice`）。深拷贝递归复制：原生 `structuredClone`（支持循环引用/Map/Set，不支持函数与 DOM）；`JSON.parse(JSON.stringify())`（丢 `undefined`/函数/Symbol，`Date` 变字符串，遇循环引用报错）；手写递归 + `WeakMap` 处理循环引用；`lodash.cloneDeep`。
6. 防抖：连续触发只执行最后一次（搜索联想、输入校验）；节流：固定窗口内最多执行一次（滚动、resize）。实现：记录 timer id，`this`/参数透传，提供 `cancel`；lodash 版支持 `leading/trailing/maxWait`。

## 四、异步编程与事件循环（2 题）

**7. 介绍一下 JS 中 `setTimeout` 的运行机制 / 事件循环** 🟡
**8. Promise、async/await 的作用与用法？`Promise.all` 与 `Promise.allSettled` 区别？** 🟡

**参考答案**
7. 单线程 + 任务队列：同步代码 → 清空微任务队列 → 取一个宏任务 → 再清微任务，循环。宏任务：`setTimeout/setInterval`、I/O、UI 事件；微任务：`Promise.then`、`queueMicrotask`、`MutationObserver`。Node 中 `process.nextTick` 优先于 Promise 微任务。
8. Promise 三态 pending/fulfilled/rejected，状态只变一次；`then/catch/finally` 返回新 Promise 支持链式。`Promise.all` 任一失败即整体失败（快速失败）；`allSettled` 等全部结束并返回每个结果状态（适合批量请求统计）。`async/await` 是 Promise 语法糖，`await` 会挂起函数并把后续代码放入微任务，`try/catch` 捕获异常；循环内 `await` 会串行，注意用 `Promise.all` 并发。

## 五、TypeScript（2 题）

**9. 类型别名 `type` 和 `interface` 有什么区别？** 🟡
**10. `unknown` 和 `any` 有什么区别？** 🟡

**参考答案**
9. `interface` 支持声明合并、可 `extends` 类/接口，不能表示联合/映射类型；`type` 可以做联合/交叉/条件/映射/模板字面量类型，但无声明合并。实践：描述对象结构用 `interface`，组合复杂类型用 `type`。
10. `any` 关闭类型检查，所有操作放行，错误推迟到运行时；`unknown` 是 top type，**必须先收窄**才能使用，是 `any` 的安全替代（外部输入一律先 `unknown` 再守卫）。

## 六、React（2 题）

**11. 什么是 Virtual DOM？使用虚拟 DOM 一定更快吗？** 🟡
**12. React Hooks 中最容易踩的坑是什么？（闭包/依赖问题）** 🟡

**参考答案**
11. JS 对象描述 UI 树 → diff 出最小变更 → 批量提交真实 DOM。优势是声明式、跨平台、避免直接操作 DOM、批量更新减少重排。**不一定更快**：首次要构建虚拟树、diff 本身有成本，小而频繁的更新直接改 DOM 可能更快；React 18 并发渲染进一步优化调度。`key` 决定节点复用与移动判定，用错会导致状态错位与无谓重建。
12. `useEffect` 依赖数组决定重跑时机，漏依赖就读到过期值（stale closure）。解法：补全依赖、函数式更新 `setState(prev => ...)`、`useRef` 存最新值、拆分 Effect、纯计算放 `useMemo`；`useEffect` 返回函数用于清理（定时器、订阅、监听、请求中止）。

## 七、Vue（2 题）

**13. 使用 `Object.defineProperty` 做数据劫持有什么缺点？** 🔴
**14. Vue 3 有哪些新特性？相比 Vue 2 有哪些变化？** 🟡

**参考答案**
13. 无法监听**新增/删除属性**（需 `Vue.set`/`Vue.delete`）；无法监听**数组下标与长度**（需重写数组方法）；初始化需递归深度遍历每个属性，性能开销大。Vue3 改用 `Proxy`，可拦截新增删除、任意 key，惰性代理且能拦截数组下标。
14. 响应式改用 `Proxy`；新增 Composition API 与 `<script setup>`；编译期优化（静态提升、Patch Flag）、Tree-shaking 更好、运行时更小；新增 `Teleport`、`Suspense`、Fragment 多根节点、`emits` 选项、`v-model` 多值。

## 八、Node.js（2 题）

**15. 什么是 Node.js？有哪些特点？适用于哪些场景？** 🟢
**16. Express.js 和 Koa.js 有什么区别？** 🟡

**参考答案**
15. V8 + 事件驱动 + 非阻塞 I/O + 单线程 JS + libuv 线程池。适合 I/O 密集型（API 网关、BFF、SSR、构建工具、实时通信）；CPU 密集型需 `worker_threads` 或多进程/集群。本仓库服务端为 Express + ES/Redis。
16. Koa：极简核心、洋葱模型中间件（`await next()`）、默认 async/await，但官方中间件少、错误处理需自己处理。Express 5：中间件模型成熟、生态与文档最全、上手快，Express 5 修复了异步错误处理。

## 九、前端工程化（2 题）

**17. 什么是前端工程化 / 模块化？`export default` 和 `module.exports` 有什么区别？** 🟡
**18. Vite 的原理是什么？为什么启动比 Webpack 快？** 🟡

**参考答案**
17. 工程化 = 模块化 + 组件化 + 自动化（构建/lint/测试/CI）+ 部署。模块化演进：命名空间 → CommonJS（运行时 require）→ AMD → ESM（编译期静态分析，tree-shaking 前提）。`export default` 属 ESM，导出匿名默认值、可多个具名导出；`module.exports` 属 CommonJS，导出整个对象。二者同一文件不可混写。
18. 开发期基于浏览器原生 ESM **按需编译**：浏览器请求哪个模块才转译哪个（O(模块数) 而非 O(依赖数)）；esbuild 预构建依赖（把 CJS 转 ESM 合并，减少请求）；HMR 边界清晰、源码级即时更新。生产期用 Rollup 打包，配合 `manualChunks` 拆分、压缩、小资源内联。

## 十、网络 / HTTP / 跨域（2 题）

**19. 如何处理跨域请求？常见方案及优缺点？** 🟡
**20. 从输入 URL 到页面显示，发生了什么？** 🟡

**参考答案**
19. **CORS**：官方标准，服务端设 `Access-Control-Allow-Origin` 等响应头；简单请求直发，预检（OPTIONS）需后端配合；带凭证时不能 `*`。**JSONP**：靠 `<script>` 绕过同源，只支持 GET、有注入风险，不推荐。**开发代理**：本仓库 `config/proxy.ts` + Umi proxy 绕过浏览器同源；生产用 Nginx 反代。**postMessage**：跨窗口/iframe。**WebSocket**：不受同源策略限制。
20. DNS 解析 → TCP 三次握手 → TLS 握手 → 发送 HTTP 请求 → 响应 → 解析 HTML 构建 DOM → 解析 CSS 构建 CSSOM → 合成 Render Tree → Layout → Paint → Composite。优化抓手：减少关键资源数量、减小资源体积、提前建连（preconnect/dns-prefetch）、SSR 降低白屏。

## 十一、性能优化与浏览器渲染（2 题）

**21. 前端性能优化的核心指标有哪些？如何衡量？** 🟡
**22. React 路由懒加载的原理是什么？还有哪些加载性能优化手段？** 🟡

**参考答案**
21. LCP、FCP、CLS、INP、TTFB；工具：DevTools Performance、Lighthouse、RUM。原则：先测量定位瓶颈（网络 / 主线程 / 渲染），再优化；区分实验室数据与真实用户指标。
22. `import()` 返回 Promise，编译为独立 chunk 请求，配合 `React.lazy` + `<Suspense>`（Vue 用 `() => import()` + 路由懒加载）渲染加载态。其他手段：图片懒加载与响应式（`srcset`/`loading="lazy"`）、`preload/prefetch`、CDN + Brotli/Gzip、首屏数据与接口并行、骨架屏。

## 十二、移动端适配与前端场景题（2 题）

**23. 移动端网站和响应式网站有什么区别？项目中如何做移动端适配？** 🟡
**24. 什么是点击穿透？怎么解决？** 🟡

**参考答案**
23. 移动端站点是独立站点（独立域名/模板/UA）；响应式是同一套代码用媒体查询 + 弹性布局适配多端。手段：`rem`/`vw` 方案（`postcss-pxt-to-viewport` + flexible.js）、Flex 布局、`@media` 断点（375/414/768）、`viewport` meta、刘海屏安全区 `env(safe-area-inset-bottom)`、输入框字号 ≥16px 防 iOS 缩放、1px 边框用 `transform: scaleY(0.5)`。
24. 原因：移动端点击延迟 + 事件冒泡，遮罩消失前点击穿透到下层元素。解决：遮罩用 `pointer-events: none` 防穿透；`touchstart` + `preventDefault`（现代浏览器已无 300ms 延迟，可不用 fastclick）；触发后立即隐藏遮罩并 `stopPropagation`；`touch-action: manipulation` 去掉双击缩放延迟。
