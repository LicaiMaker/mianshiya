# 前端面试题 - 2026-10-13

> 每日精选，覆盖前端各技术方向，每个方向 ≥2 道题。题源参考本仓库及 mianshiya.com。

## 一、HTML / CSS

1. **盒模型与 BFC**
   - 描述一下 W3C 标准盒模型与 IE 怪异盒模型的区别，`box-sizing` 属性的取值对布局有什么影响？什么是 BFC？哪些 CSS 属性可以触发 BFC？BFC 解决了什么问题？

2. **CSS 布局与居中方案**
   - 至少列出 4 种使一个 div 在父容器中水平垂直居中的方案（要求至少包含一种不使用 `transform` 的方案），并说明各自兼容性。

3. **响应式与单位**
   - 说说 `rem`、`em`、`vw/vh`、`%`、`px` 的差异，移动端适配（rem 方案、vw 方案、postcss-px-to-viewport）各自的工作原理是什么？

## 二、JavaScript 基础

4. **原型与原型链**
   - 解释一下 JS 中的原型对象、`__proto__`、`prototype`、`constructor` 三者的关系。`Function.prototype` 是什么？一切函数是否都是 `Function` 的实例？

5. **作用域 / 闭包 / 变量提升**
   - 什么是词法作用域？什么是闭包？闭包的使用场景与内存泄漏风险分别是什么？结合一段 `var`/`let`/`setTimeout` 的代码说明变量提升与暂时性死区。

6. **this 指向**
   - 详述函数调用、对象方法调用、`new` 调用、`call/apply/bind`、箭头函数中 `this` 的差异，并手写 `bind` 的 polyfill。

## 三、JavaScript 进阶

7. **事件循环**
   - 浏览器中的事件循环（宏任务 / 微任务）执行顺序是什么？Node.js 中的事件循环与浏览器有什么区别？`process.nextTick`、`Promise.then`、`queueMicrotask`、`setImmediate` 的优先级？

8. **深拷贝**
   - 实现一个深拷贝函数，需要处理：循环引用、Date/RegExp/Map/Set/Symbol、函数、原型链上的属性。考虑 WeakMap 解决循环引用的写法。

9. **防抖与节流**
   - 手写防抖（debounce）与节流（throttle），并说明在搜索输入、滚动加载、按钮点击场景下分别适合使用哪一种？为什么？

## 四、ES6+

10. **Promise / async await**
    - Promise 有哪几种状态？`.then` 返回值、`Promise.all`、`Promise.race`、`Promise.allSettled`、`Promise.any` 的行为差异是什么？async/await 的本质是什么？如何串行执行一组异步任务？

11. **模块化**
    - 说说 CommonJS、AMD、CMD、ES Module 的差异，循环引用时各自如何处理？tree-shaking 原理是什么？为什么 ES Module 支持而 CommonJS 不支持？

## 五、TypeScript

12. **类型系统**
    - 解释 `interface` 与 `type` 的区别；`any`、`unknown`、`never` 的使用场景分别是什么？联合类型与交叉类型如何结合使用？

13. **泛型与类型推导**
    - 手写一个泛型工具函数 `MyAwaited<T>`，模拟 `Awaited<T>` 的递归解包效果。说明条件类型 `T extends U ? X : Y` 与 `infer` 的用法。

## 六、Vue

14. **响应式原理**
    - Vue 2 通过 `Object.defineProperty` 实现响应式，Vue 3 通过 `Proxy` 实现，二者差异是什么？Vue 3 的响应式 API（`ref`、`reactive`、`computed`、`effect`）底层实现是怎样的？

15. **生命周期与 diff**
    - Vue 2 / Vue 3 的生命周期钩子分别是什么？父子组件嵌套时执行顺序如何？Vue 的 diff 算法做了哪些优化（key、双端比较、静态标记）？

16. **组件通信**
    - 列举至少 6 种 Vue 组件间通信方式，说明各自的适用场景，并对比 `provide/inject` 与 `eventBus` 的优劣。

## 七、React

17. **Fiber 与调度**
    - React Fiber 解决了什么问题？双缓存机制（current tree / workInProgress tree）是什么？React 18 的 concurrent mode 与自动批处理（automatic batching）原理？

18. **Hooks 原理**
    - 解释 `useState`、`useEffect`、`useMemo`、`useCallback` 的实现原理。为什么 hooks 不能写在条件语句中？手写一个 `useState` 的简化版实现。

19. **组件渲染与性能优化**
    - `React.memo`、`PureComponent`、`useMemo`、`useCallback`、`key`、虚拟列表（react-window）分别解决什么性能问题？React 18 中 `useTransition` 和 `useDeferredValue` 的使用场景？

## 八、浏览器与网络

20. **从输入 URL 到页面渲染**
    - 详细描述从用户在浏览器输入 `https://mianshiya.com` 到页面完整渲染的整个过程（DNS、TCP、TLS、HTTP、渲染流水线、首屏优化）。

21. **HTTP / HTTPS**
    - HTTP/1.1、HTTP/2、HTTP/3 的关键差异是什么？HTTPS 的握手流程（TLS 1.2 / TLS 1.3）是什么？队头阻塞（HOL blocking）是如何被解决的？

22. **跨域与缓存**
    - 跨域解决方案（CORS、JSONP、postMessage、Nginx 反代、WebSocket）有哪些？强缓存（Expires / Cache-Control）与协商缓存（Last-Modified / ETag）流程是怎样的？

## 九、性能优化

23. **首屏 / 加载优化**
    - 列举常见的首屏优化手段（CDN、SSR/SSG、懒加载、Tree Shaking、Code Splitting、preload/prefetch、http 缓存等），并按"网络层 / 资源层 / 渲染层"分类。

24. **运行时性能**
    - 长列表卡顿如何优化？React/Vue 中如何避免不必要的重渲染？聊聊 virtual list、requestAnimationFrame、Web Worker 的使用边界。

## 十、工程化

25. **Webpack / Vite**
    - Webpack 的构建流程（初始化 → 编译 → 输出）是什么？Loader 与 Plugin 的区别？Vite 为什么比 Webpack 快？ESM、按需编译、esbuild、Rollup 各扮演什么角色？

26. **Babel / Polyfill**
    - Babel 的编译流程（parse → transform → generate）是什么？`@babel/preset-env`、`core-js`、`useBuiltIns: 'usage'` 的关系？core-js 3 与 core-js 2 的差异？

27. **CI / 规范**
    - 前端工程化中常见的代码规范工具（ESLint、Prettier、Stylelint、Husky、lint-staged、Commitlint）如何分工与协作？为什么要区分 lint 与 format？

## 十一、Node.js

28. **事件循环与 Stream**
    - Node.js 中 libuv 的事件循环 6 个阶段是什么？process.nextTick 与 Promise.then 的执行顺序？Stream（Readable/Writable/Transform/PassThrough）解决了什么问题？

29. **Koa / Express 中间件**
    - 手写一个最简 Koa 中间件机制（compose 函数），解释洋葱模型。Koa 与 Express 的中间件模型差异是什么？

## 十二、设计模式 / 架构

30. **常见模式在前端的应用**
    - 举例说明发布订阅模式、观察者模式、单例模式、工厂模式、策略模式在前端中的应用场景（至少举 4 个模式的具体例子）。

31. **前端架构**
    - 聊聊你对"微前端"的理解，qiankun、micro-app、Module Federation（webpack 5）各自的实现原理与优劣？什么时候适合引入微前端？
